# GDG Essex — 150-minute facilitation plan

| Time | Duration | Activity |
|---|---:|---|
| 0–5 | 5 min | Welcome, outcomes and Colab readiness check |
| 5–25 | 20 min | Opening talk: agentic data systems, the ten concepts, business scenario, data/agent architecture and safety boundaries |
| 25–50 | 25 min | Notebook 1 — Build Your First Enterprise Data Agent |
| 50–85 | 35 min | Notebook 2 — Give Your Agent Enterprise Expertise |
| 85–90 | 5 min | Break |
| 90–125 | 35 min | Notebook 3 — Build the Multi-Agent System |
| 125–145 | 20 min | Compare implementation tracks, optional integrations, advanced challenge and Q&A |
| 145–150 | 5 min | Recap, next steps and close |

**Total: 150 minutes.** Notebook 0 is completed before the event; Notebook 4 is post-workshop reference material. Optional integrations are shown or discussed only if time and access permit; they are not required to complete the core labs.
